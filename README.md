# Portfolio – Akim Ayena Soule Amidou

Professional portfolio developed with **Next.js**, **Tailwind CSS** and **TypeScript**.

## Getting Started

First, run the development server:

```bash
git clone https://github.com/HakimAsa/portfolio.git
cd portfolio
npm install
npm run dev
# or
yarn install
yarn dev
# or
pnpm install
pnpm dev
# or
bun install
bun dev
```

## Deploy on Vercel

This site is hosted on [Vercel](https://vercel.com)
